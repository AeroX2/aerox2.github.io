Nullify

Product Engineer

March 2026–present

UI2 frontend rebuild.

I rebuilt UI2 with Vite and an atomic design architecture covering about 470 components. I owned the architecture and built most features, with help from colleagues on some features.

The new UI was faster and worked better on mobile. Screens looked consistent, navigation was easier to follow, and accessibility scores improved. I set the design direction and used Claude Design to try out ideas. I also built quick prototypes to explore how proposed features could work.

I added screenshot comparisons to catch visual regressions and end-to-end tests for UI flows. When AI-generated code kept repeating the same mistakes, I used an LLM to build ESLint rules for component dependencies, colour tokens, and shared UI elements.

How the visual checks work

Playwright captures selected Storybook components in light and dark themes. ImageMagick compares them with screenshots from before the change and posts the differences on the pull request.

Personal projects

C++ inference / Python / Raspberry Pi

An e-paper frame that generates its own art.

I wanted an e-paper art frame that generated its own images locally. Getting it working took me into model exports, tensor dimensions, tokenisation, and image-quality bugs.

I added SDXL Turbo support to OnnxStream’s C++ inference engine and contributed fixes to tokenisation, VAE scaling, and XNNPACK integration. Five pull requests were merged upstream.

The finished frame connects inference, a Python service, image history, web controls, and colour processing for the physical display. It sits on my shelf and runs every day.

Tracking down repeated image content

To investigate mismatched output, I decoded OnnxStream’s latents using the Diffusers VAE to help isolate the cause. Working with the maintainer, I corrected the export’s latent dimensions to resolve repeated image content. Later fixes addressed decoder scaling and CLIP tokenisation.
